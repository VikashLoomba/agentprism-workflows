# Archive

Historical design records from past implementation trains: the design notes that once described
the architecture, and the per-train specifications that guided each build. They are kept for
provenance only.

- **Not maintained.** Nothing here is updated when the code changes.
- **Not an authority.** The code, its tests, the READMEs, `docs/api.md`, and `docs/authoring/`
  describe current behavior. Where a document here disagrees with the code, the document is wrong.
- **Not a constraint.** Words like "frozen", "contract", and "implementation authority" inside
  these files described a moment in a past train. They bind nothing now.

Agents: do not read these unless the user points you at a specific file. Design from first
principles and from the code; see [`AGENTS.md`](../../AGENTS.md).
